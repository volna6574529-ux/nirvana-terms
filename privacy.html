Политика конфиденциальности
Дата обновления: 27 сентября 2026 года

1. Общие положения

Настоящая политика конфиденциальности описывает, какие данные может обрабатывать Discord-бот NIRVANA при использовании его функций.

Используя NIRVANA, пользователь соглашается с данной политикой конфиденциальности.

2. Какие данные могут обрабатываться

В зависимости от используемых функций NIRVANA может обрабатывать следующие данные:

  • ID пользователя Discord;
  • ID Discord-сервера;
  • ID каналов и сообщений, необходимые для работы команд;
  • имя пользователя и отображаемое имя Discord;
  • данные, необходимые для работы розыгрышей и других функций бота.

3. Для чего используются данные

Данные могут использоваться исключительно для обеспечения работы функций NIRVANA, включая модерацию, управление сервером, розыгрыши, статистику и другие функции бота.

4. Хранение данных

Некоторые данные могут временно или постоянно сохраняться в базе данных для корректной работы функций бота.

Мы не продаём и не передаём персональные данные пользователей третьим лицам для рекламных или коммерческих целей.

5. Discord

NIRVANA работает через платформу Discord. Использование Discord также регулируется правилами и политикой конфиденциальности Discord.

6. Удаление данных

Пользователь может обратиться к владельцу NIRVANA или администрации сервера с запросом на удаление данных, которые могут быть связаны с использованием бота.

7. Безопасность

Мы принимаем разумные меры для защиты данных, связанных с работой NIRVANA. Однако ни один способ хранения или передачи данных через интернет не может гарантировать абсолютную безопасность.

8. Изменения политики

Политика конфиденциальности может периодически обновляться. Актуальная версия всегда публикуется на этой странице.

9. Контакты

По вопросам конфиденциальности и обработки данных обращайтесь к владельцу NIRVANA или администрации Discord-сервера, на котором используется бот.
